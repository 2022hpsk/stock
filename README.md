# quantstock — A股/场内基金 个人量化投研与半自动交易系统

> 目标：基于**历史与最新市场数据**、**你的实际账户资金与持仓**、**你的投资意向与风险偏好**，
> 每个交易日产出**可执行、可解释、可追溯**的操作建议，并支持**一键确认后自动下单**。

---

## 1. 这个项目是什么

一个自用的、工程化的量化投研平台，覆盖从数据采集到实盘执行的完整链路：

```
行情数据采集 ┐
             ├→ 数据治理 → 因子计算 → 策略信号 → 组合优化 → 风控校验 → 每日建议 → 人工确认 → 委托执行 → 绩效归因
情报消息采集 ┘                                        ↑                    ↑
                                              事件风险否决          证据链与解释
```

**每条建议的解释由四支柱构成**：① 量化因子依据 ② 持仓成本与技术分析 ③ 最新消息证据（带原文链接）
④ 反面证据与证伪条件。缺任一支柱的建议不会进入交易计划。

**核心定位边界（务必先读）：**

| 是 | 不是 |
|---|---|
| 个人自用的决策支持系统 | 面向他人的投顾产品（需持牌，本项目不提供任何投资建议服务） |
| 半自动：程序出草稿，人拍板 | 无人值守全自动托管 |
| 日线为主 + 多周期混合 | 日内高频/做市/套利 |
| 可复现、可审计的研究流程 | 追求"神奇指标"的黑箱 |

## 2. 关键设计决策

| 维度 | 选择 | 理由 |
|---|---|---|
| 市场 | A股（沪深主板/创业板/科创板/北交所）+ 场内基金 ETF/LOF | 用户主战场；规则统一，可用免费数据源 |
| 自动化 | 半自动（Advisor 出订单草稿 → 人工确认 → Execution 提交） | 安全边界清晰，同时保留全自动的升级路径 |
| 周期 | 多周期混合（月线定仓位中枢，日线做择时，分钟线优化执行价） | 兼顾稳健与灵活 |
| 数据源 | 多源适配 + 自动降级（AkShare / BaoStock / Tushare / 交易所直采） | 免费源为主，单点故障不致命 |
| 存储 | Parquet 列存 + DuckDB 查询层 | 单机零运维，分析型查询快，天然支持 point-in-time |
| 回测 | 自研事件驱动引擎为准绳 + 向量化引擎做参数扫描 | 向量化快但容易失真，撮合真实性以事件驱动为准 |
| 交易通道 | miniQMT / XtQuant 适配（可插拔），默认 PaperBroker | 个人可开通、有官方 Python 接口 |
| 金额计算 | `Decimal`，禁止 `float` | 资金计算不允许浮点误差 |

## 4. 快速开始

```bash
# 依赖管理使用 uv
uv sync --all-extras

# 代码检查（提交前必跑）
make check          # ruff + mypy + pytest

# 初始化本地数据湖（首次约 20-40 分钟）
uv run quantstock data init --start 2015-01-01

# 每日增量更新
uv run quantstock data update

# 采集当日全域消息并生成分域摘要
uv run quantstock intel fetch --domain ALL
uv run quantstock intel digest

# 外置导入：把任何文件丢进收件箱即可，或直接命令行录入
cp ~/我的研报.md var/intel/inbox/
uv run quantstock intel note "某公司大额订单落地" --symbol 002415.SZ --importance 80

# 生成今日操作建议
uv run quantstock advise --account main --output report

# 确认并执行（半自动，逐单确认）
uv run quantstock execute --plan var/plans/2026-07-27.json --confirm
```

## 5. 目录结构

```
src/quantstock/
├── config/      配置模型与加载（pydantic-settings）
├── infra/       日志、缓存、时钟、交易日历、异常、存储
├── data/        数据源适配器 + 数据湖读写 + 质量校验
├── intel/       信息情报：多源资讯采集、去重、事件分类、外置导入、分域摘要
├── factors/     因子计算（技术/基本面/资金/情绪）
├── strategy/    策略与信号生成
├── backtest/    回测引擎、撮合、成本模型、绩效指标
├── portfolio/   目标组合构建与仓位分配
├── risk/        风控规则引擎与熔断
├── account/     账户/持仓/资金同步与对账
├── advisor/     每日操作建议编排与解释生成
├── execution/   券商适配层与订单管理
├── reporting/   报告渲染与绩效归因
└── cli/         命令行入口
```

## 6. 免责声明

本项目为**个人技术研究用途**。所有输出均为程序基于历史数据的统计结果，**不构成任何投资建议**。
证券市场有风险，历史回测收益不代表未来表现。使用者需对自己的全部交易决策与后果负责。

## 7. 分支策略

本仓库采用 **trunk-based，仅保留唯一 `main` 分支**。每完成一组有意义的变更即提交并推送到 `main`。
