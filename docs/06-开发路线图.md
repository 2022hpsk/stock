## M3 · 决策闭环
- [ ] `account`：手工 YAML 持仓录入、T+1 可卖量、成本与盈亏核算
- [ ] 投资意向配置模型（`accounts.yaml`）
- [ ] 内置策略：`macro_exposure`、`quality_value`、`momentum_trend`、`etf_rotation`、`timing_overlay`
- [ ] 多周期融合（LONG 定仓位 × MEDIUM 定选股 × SHORT 定择时）
- [ ] `portfolio`：目标权重、约束应用、调仓差分、缓冲带、整手对齐
- [ ] `risk`：A/B/C 三类规则 + 熔断状态机 + `RiskDecision`
- [ ] `advisor`：`TradePlan` 生成 + 日报（Markdown/终端）+ `--explain`
- [ ] **`RationaleBundle` 四支柱解释**：量化依据 / 持仓与技术分析 / 情报证据 / 反面证据
- [ ] `PositionAnalyzer`：持仓成本线、持有期超额、技术形态、支撑压力、ATR 止损位
- [ ] 解释完整性校验（缺支柱的建议不进入 `TradePlan`）

**验收**：录入真实持仓与资金后，`quantstock advise` 输出完整可执行日报；每条建议可追溯到
因子值、技术形态、情报原文链接与风控规则判定，且必须包含反面证据与证伪条件。

## M5 · 实盘接入
- [ ] `XtQuantBroker`（miniQMT）：行情、下单、撤单、查询、成交回报
- [ ] 账户实时同步与对账（程序账本 vs 券商账本差异检测）
- [ ] 盘中监控：止损止盈提醒、熔断监控、异动提醒
- [ ] 资金面与信息面数据（F1.4 / F1.5）+ 新闻情绪软因子
- [ ] **小资金实盘验证期**：先用 ≤10% 资金跑满 3 个月，对比计划与实际

**验收**：连续 1 个月实盘无重复下单、无越权下单、无风控绕过；程序账本与券商对账差异为 0。

## 风险与依赖

| 风险 | 缓解 |
|---|---|
| 免费数据源接口不稳定/变更 | 多源降级 + 质量校验 + 适配器隔离，接口变更只改一个文件 |
| 策略过拟合 | 强制样本外 + walk-forward + 成本敏感性；无经济学逻辑不入实盘 |
| miniQMT 需券商开通权限 | `ManualBroker` 作为兜底，不阻塞 M1–M4 |
| 实盘与回测偏差 | 保守撮合假设 + 小资金验证期 + 计划-实际偏差监控 |
| 监管规则变动（费率/涨跌幅） | 全部做成按生效日期的区间配置表，非硬编码 |
