- [ ] `llm/` 模块：客户端（缓存/限流/重试/预算/成本记账）、三种模式 `off`/`live`/`replay`

- [ ] **L2 研判归纳** → `conviction_adjustment`（LLM 唯一数值出口，α 限幅 0.15）
- [ ] **L3 解释生成**（组织四支柱行文，不改任何数字）
- [ ] 匿名化 + 日期脱敏；**泄漏检测测试**（真实名 vs 虚构名差异率 < 10%）
- [ ] `llm backfill` / `coverage` / `cost-estimate`：历史区间批量预计算
- [ ] **回测强制 replay**：实时调用抛 `LLMLiveCallInBacktestError`（测试覆盖）
- [ ] **A/B 回测**：`backtest ab --arm-a "llm.mode=off" --arm-b "llm.mode=replay"` + α 敏感性扫描
- [ ] 界面：🤖 标记与展开视图、用量费用页、LLM 总开关与 α 滑块

**验收**：
1. 同一缓存跑两次回测，结果**逐笔完全一致**；
2. `llm.mode=off` / API 超时 / 返回非法 JSON 三种情况下系统**照常出建议**；
3. 属性测试证明 `final_score` 相对 `base_score` 的偏移永远 ≤ α；
4. `risk`/`portfolio`/`execution` 包静态检查无对 `llm` 的 import；
5. **A/B 回测显示 LLM 在样本外有净增量**（扣除 API 成本后），否则默认保持关闭。
